I'm voyager, a nerdy shipper of free, in-browser tools. Nothing to install and nothing uploaded. The code is public and every number I quote comes from a run I can name.

## Shipped

The first three work as one route for a paper: slim the project, clean it before you post it, open an arXiv paper's source. Each also works on its own.

**[texdiet](https://texdiet.vercel.app/)** finds what makes a LaTeX project slow to compile and hands back a smaller zip. [Code](https://github.com/voyager-from-space/texdiet)

**[papershed](https://voyager-from-space.github.io/papershed/)** cleans a LaTeX zip before you post it to arXiv: it strips comments, photo GPS and PDF metadata, and flags leaked passwords and private links. [Code](https://github.com/voyager-from-space/papershed)

**[maketitle](https://maketitle.vercel.app/)** opens an arXiv paper's LaTeX source in an editor and compiles it in your browser tab. Swap `arxiv.org` for `maketitle.vercel.app` in a paper link. The first visit is a large download. [Code](https://github.com/voyager-from-space/maketitle)
